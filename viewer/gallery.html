Skins

Every skin in skins/, drawing the same run. A skin is one JSON file and decides all of this — colours, lane names, the icon for each event type, the layout, and how long a tool may go unanswered before the view says so.

Adding one. Write a JSON file, drop it in skins/, and it appears here and in the picker. The schema and every stylable event type are in skins/README.md. Open a pull request when it looks right — one skin per file, with an author and a one-line blurb. There is no taste requirement: legible on a projector, all one colour, or nothing but tool calls are all reasonable things to want.
